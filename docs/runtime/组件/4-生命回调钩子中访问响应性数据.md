## 生命回调钩子中访问响应性数据

根据之前的描述，我们只需要 改变生命周期钩子的 this 指向即可：

以下是格式化后的代码和描述：

1. 在 `packages/runtime-core/src/component.ts` 中为 `callHook` 方法增加参数，以此来改变 `this` 指向：

```typescript
/**
 * 触发 hooks
 */
function callHook(hook: Function, proxy: any) {
  hook.bind(proxy)();
}
```

2. 在 `applyOptions` 方法中为 `callHook` 的调用，传递第二个参数：

```typescript
// hooks
if (beforeCreate) {
  callHook(beforeCreate, instance.data);
}
...
// hooks
if (created) {
  callHook(created, instance.data);
}
```

3. 在 `registerLifecycleHook` 中，为 `hook` 修改 `this` 指向：

```typescript
function registerLifecycleHook(register: Function, hook?: Function) {
  register(hook?.bind(instance.data), instance);
}
```

创建对应测试实例 `packages/vue/examples/runtime/render-component-hook-data.html`：

```html
<script>
  const { h, render } = Vue;

  const component = {
    data() {
      return {
        msg: "hello component",
      };
    },
    render() {
      return h("div", this.msg);
    },
    // 组件实例处理完所有与状态相关的选项之后
    created() {
      console.log("created", this.msg);
    },
    // 组件被挂载之后
    mounted() {
      console.log("mounted", this.msg);
    },
  };

  const vnode = h(component);
  // 挂载
  render(vnode, document.querySelector("#app"));
</script>
```

数据访问成功
