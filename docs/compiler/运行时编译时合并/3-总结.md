## 总结

到这里我们已经成功的完成了 **运行时 + 编译器** 的合并逻辑，那么我们可以运行如下测试实例，来查看一个相对完整的测试实例：

```html
<script>
  const { createApp } = Vue;
  const APP = {
    template: `<div>hello world, <h1 v-if="isShow">{{ msg }}</h1></div>`,
    data() {
      return {
        msg: "你好，世界",
        isShow: false,
      };
    },
    created() {
      setTimeout(() => {
        this.isShow = true;
      }, 2000);
    },
  };

  const app = createApp(APP);
  app.mount("#app");
</script>
```
